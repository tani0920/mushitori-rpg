# むなかた虫とり日記

小学生が夏休み最後の14日間（8/13〜8/26）、宗像市で虫をつかまえて昆虫図鑑を完成させる虫とりRPG（プロトタイプ）。

**遊ぶ：** https://tani0920.github.io/mushitori-rpg/

iPhone・iPadは Safari で開いて「共有 → ホーム画面に追加」すると、アプリのように全画面で遊べます。

- 仕様・素材リスト：[企画メモ.md](企画メモ.md)
- 登場する「ミアレカブト」は、このゲームのための架空の昆虫です（宗像大社のみあれ祭にちなんだ名前）。ほかの30種は実在する昆虫です。
- ChatGPTで絵を作るプロンプト：[ChatGPT画像プロンプト.md](ChatGPT画像プロンプト.md)
- ドット絵の差し替え：`img/bugs/<id>.png` を置いて、`index.html` の `USE_IMAGE_FILES` を `true` に
